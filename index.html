qemu

aldan also runs on a stock qemu risc-v virt machine. download the image and unpack it: it holds bootmgr.bin (firmware) and disk.img. then:

  1. install qemu with risc-v support (qemu-system-riscv64, version 8 or newer)
  2. open a terminal in the unpacked folder
  3. start the machine with the firmware as bios, the disk on an nvme device, and a virtio display and keyboard: 
    qemu-system-riscv64 -M virt -m 16M -smp 1 \
  -display sdl -serial stdio -monitor none \
  -cpu rv64,v=true,vlen=256,zba=true,zbb=true,zbs=true,num-triggers=8 \
  -bios bootmgr.bin \
  -drive file=disk.img,if=none,id=d0,format=raw,snapshot=on \
  -device nvme,drive=d0,serial=aldan \
  -netdev user,id=n0 -device virtio-net-device,netdev=n0 \
  -device virtio-keyboard-device \
  -device virtio-gpu-device,xres=1560,yres=1040 \
  -global virtio-mmio.force-legacy=false
  4. on macos use -display cocoa,zoom-to-fit=on instead of -display sdl
  5. close the window to quit; snapshot=on keeps disk.img untouched, so changes are not saved

for convenience the archive also has run.sh, which runs the same command.
